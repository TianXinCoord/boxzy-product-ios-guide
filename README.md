# BOXZY 产品说明书 · 新旧 UI 对照

2026-10-19 同步已确认的 UI 更新，共 39 个模块，其中 21 个模块标记「存在UI优化」。

## 离线使用

1. 克隆仓库，或通过 GitHub 的 Code → Download ZIP 下载并解压。
2. 用浏览器打开 `BOXZY-iOS-PRODUCT-GUIDE.html`。
3. 保留同级 `assets` 文件夹。当前文档引用 82 个本地图片资源（含独立背景下载），无外部资源依赖。

仓库版将单文件 HTML 中的图片拆为本地资源，以避免 GitHub 的单文件大小限制；页面文字、图片内容和交互与离线单文件版一致。`image-manifest.json` 记录每张引用图片的 SHA256 和转换校验。

## 阅读方式

- 已优化模块按「老图 → 新图 → 说明文字」展示。老图优先使用提供的截图，其余沿用原 HTML 图片。
- 快速导航标记「存在UI优化」，支持搜索与仅显示优化项。
- 多状态页面可切换查看；新旧图对应状态同步，点击图片可放大。
- 保留历史说明全文供对照，并补充当前确认的修改和交互规则。
- 修改用户名保留原来的 6 张状态图，不标为 UI 优化。

提现使用保留金额输入及数字键盘结构的版本；无收款账户仅调整下方账户区域。浮窗关闭规则、地址内容与浮窗外壳尚未完全对齐之处，均在对应说明中注明。

截图金额、手续费、限额及到账时间为演示值，正式业务规则以对应说明和服务端配置为准。此仓库是 UI 与产品文档，本次未修改原生 App 或 Web 业务代码。历史说明和旧图不代表当前最终要求。
